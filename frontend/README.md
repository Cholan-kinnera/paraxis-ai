# Paraxis AI — Web Frontend (`frontend`)

The Next.js 14 web application for Paraxis AI, serving both the student/reporter portal and the operational Command Center.

## Tech Stack
- Next.js 14+ (App Router)
- React 18+
- TypeScript
- Tailwind CSS
- Lucide Icons
- TanStack Query

## Booting Locally
```bash
npm install
npm run dev
```
Application accessible at: `http://localhost:3000`  
Health probe available at: `http://localhost:3000/api/health`
