# Test Suites — Paraxis AI

Unified testing directory organized by scope:
- `contract/`: Cross-service API schema and event format tests.
- `integration/`: Multi-service database, cache, and internal API integration tests.
- `e2e/`: Playwright browser automation tests.
- `evaluation/`: AI offline evaluation datasets and regression suites.
- `fixtures/`: Deterministic campus graphs and mock operational reports.
